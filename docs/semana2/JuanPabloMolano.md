## Mis historias de usuario

> Entre 5 y 7 historias en formato "como [rol] quiero [acción] para [beneficio]", pensadas desde distintos roles o necesidades del producto que el equipo está diseñando. Si escribes menos de 7, borra las líneas que no uses (mínimo 5).

1. Como colombiano que envía dinero desde EE.UU., quiero indicar qué gasto esencial busco cubrir, para que el envío tenga un propósito de pago claro.
2. Como familiar en Colombia, quiero usar el dinero recibido para pagar el gasto esencial indicado, para atender esa necesidad.
3. Como remitente, quiero saber si el gasto quedó pagado, para no depender solo de mensajes informales para comprobarlo.
4. Como remitente, quiero conocer el costo total del envío y el monto disponible para el pago antes de confirmarlo, para decidir si alcanza para el gasto.
5. Como familiar en Colombia, quiero conocer el estado del dinero destinado al gasto, para saber si ya puedo realizar el pago.
6. Como remitente, quiero seguir el estado del envío hasta el pago, para identificar si hace falta alguna acción antes de que venza la obligación.
7. Como remitente, quiero consultar un comprobante del pago, para conservar evidencia de que se cubrió el gasto.
